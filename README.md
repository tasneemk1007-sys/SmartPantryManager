# Smart Pantry Manager

Smart Pantry Manager is an Android application developed for the Mobile App Development 700 module.

The application allows users to keep track of ingredients available in their pantry and receive recipe suggestions based on the ingredients they currently have. A recipe is only suggested when all of its required ingredients are available in sufficient quantities.

## Features

- Add pantry ingredients
- Edit existing ingredients
- Delete ingredients
- Store ingredient quantities and units
- Store optional expiry dates
- View available pantry ingredients
- View suggested recipes
- View recipe details and instructions
- Settings screen
- Expiring-soon ingredient alerts
- Recipe matching based on available ingredients

## Database

The application uses SQLite for local data storage.

SQLite was chosen because it provides persistent local storage directly on the Android device and does not require an internet connection or an external database server. Pantry ingredients and recipe information can therefore be stored and accessed efficiently within the application.

## Technologies Used

- Java
- Android Studio
- XML
- SQLite
- RecyclerView
- Git and GitHub

## How to Run the Application

1. Download or clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle to finish syncing.
4. Start an Android emulator or connect an Android device.
5. Run the application from Android Studio.
